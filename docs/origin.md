## 3. 设计语境：为什么长这样

| 决定 | 来自什么约束 |
| --- | --- |
| 5×7 字模 | 「LED 矩阵风」；5×7 是拉丁字母的最小可读栅格，也是点阵招牌的通用规格 |
| 单层 SVG 圆点 + 13% 底点 | 屏质感：真机未点亮的 LED 也是**可见的暗点**，全黑会像"缺了一块" |
| 纯 CSS / 零依赖 / no-JS / SSR | 站点整体取向（静态导出、首帧即动画、不引运行时）。WORKLOG：「no-JS 照常运转（纯 CSS）、reduced-motion 定格数字」 |
| 列相位 22ms | 让切换像**一次物理刷新**（逐格扫过），而不是淡入淡出 |
| 共用格位常亮（`dm-both`） | 重组过程中图形不散，给视觉一个锚点 |
| 三组等时轮换 | 侧栏只有一块屏，需要在一屏里轮播「态度 / 数据 / 署名」 |
| 每组 ≤ 7 字符 | 侧栏卡约 300px + 5×7 字模 → 41 列；超长只能整屏缩小，点距变密、可读性骤降 |
| `reduced-motion` 定格数值组 | 闪烁动画对前庭敏感人群不友好；定格在"有信息量"的那一组 |
| 内容一律 A–Z / 0–9 / `.-` | 5×7 放不下可读的中文；中文信息交给旁边的 DOM 文字 |

## 4. 视觉母题的参照系

> 本节是设计语境的归纳（非 Ting 原话）。

LED 点阵招牌 · 机场翻牌屏（split-flap）· 点阵打印机 · 复古数字仪表 —— 共同语言是
「离散的点、逐格刷新、刷新时带残影」。本组件的两个动作都在这条语言里：

- **重组扫掠** = 一次刷新（旧组熄灭、新组亮起、两股扫掠同时进行）
- **错点** = 刷新残影（鬼点闪烁一下才被纠正）
