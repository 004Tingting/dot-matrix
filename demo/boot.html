开机自检

整屏先全部点亮（0% 关键帧），再按列逐列退回底点——像真机通电时的自检扫过。
纯 CSS、一次性动画，不新增任何节点：直接复用那些 13% 的底点。

无构建 · 无依赖 · 可离线打开

①看一次

点「重播」重新创建一次（自检是 animation-iteration-count: 1 的一次性动画，重播 = 重新上电）。

fadeMs 单点淡出520ms
colStepMs 每列错峰18ms

      


      

        
②机制

        

          自检不是独立图层，而是给已有的底点挂一条一次性动画：起始 opacity: 1、结束 0.13，
          每列的 animation-delay = 列号 × colStepMs，配合 animation-fill-mode: both，
          所以延迟期间就已经是「全亮」状态，形成一次从左到右的扫退。
        

        
/* 根节点加 .dm-boot */
.dm-n3.dm-boot .dm-off {
  animation: dm-boot-3 520ms ease-out both;   /* 单点淡出 */
  animation-delay: 列号 × 18ms;               /* 内联，逐列错峰 */
}
@keyframes dm-boot-3 {
  0%   { opacity: 1; }     /* 全亮 */
  100% { opacity: 0.13; }  /* 退回底点 */
}

        

          
总时长列数 × colStepMs + fadeMs（41 列默认 ≈ 738 + 520 ≈ 1.26s）

          
节点开销0（复用底点，无新增元素）

          
与内容的关系自检扫退的同时，内容组照常按自己的相位重组进入（两股动画并行）

          
reduced-motion整条动画被禁用，直接停在底点

          
何时播每次挂载/重新创建播一次；SSR 首帧即播（= 上电）
