点阵屏

5×7 LED 字模 · 纯 SVG + CSS 动画 · 零依赖 · 多组定时重组轮换。
每个亮点按「组相位 + 列相位（22ms）」错峰亮灭，切换时旧组熄灭、新组亮起、两股扫掠同时进行。

无构建 · 无依赖 · 可离线打开

⑤字模表

内置 A–Z、0–9、.、-；空格与未收录字符（如中文）各占 1 格宽度但不点亮，即留白。新增字形改 src/DotMatrix.tsx 的 FONT 或 demo/dot-matrix.js 的 FONT。

⑥试验台

每行一组（自动大写；空格与未收录字符占位但不点亮）；primary 是 prefers-reduced-motion 下定格显示的组下标（自动夹取到有效范围）；animate 控制单组时是否也带闪。


        


        

          
⑦错点（glitch）· 可调

          

            每次切换后多出一批「不属于本内容」的亮点，闪烁一下后熄灭——模拟 LED 屏刷新残留的鬼点。
            density 管错点多少，patterns 管随机性
            （错点集合多少轮才重复一次），holdMs 是错点存活时长，seed 换一组「性格」。
            纯 CSS + 确定性伪随机：no-JS、SSR 与客户端输出一致（见 docs/glitch.md）。
